# iMath - Projeto Acadêmico

Este projeto é um protótipo de site e-commerce desenvolvido para a disciplina de **Programação para a Internet 1 (PI1)**, focado em estrutura web, estilização visual (com tipografia **Poppins** e **Inter**) e interatividade com eventos em JavaScript.

---

### ⚠️ Aviso de Direitos Autorais e Uso Educacional

Este repositório foi criado exclusivamente para fins educacionais e demonstrativos. Todo o conteúdo visual, marcas, nomes, logotipos, imagens, vídeos e referências à **Apple** pertencem aos seus respectivos proprietários. Nenhuma infração de direitos autorais é intencionada.

---

### 🚀 Tecnologias Utilizadas
- **HTML5** — Estruturação das páginas (`menuapple.html`, `catalogo.html`, `comparativo.html`, `contato.html`)
- **CSS3** — Estilização e layout das páginas (`menuapple.css`, `catalogoapple.css`, `comparativoapple.css`, `contatoapple.css`)
- **JavaScript** — Interatividade e eventos nas páginas (`menuapple.js`, `catalogo.js`, `comparativo.js`, `contato.js`)
