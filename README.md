# 🛒 E-commerce Institucional - iMath (Loja de iPhones)

> Status do Projeto: Em Desenvolvimento — Parte 2 (JavaScript) em andamento 🚧

## 📋 Sobre o Projeto
O **iMath** é um site institucional e-commerce desenvolvido para simular uma vitrine digital de produtos da Apple, com foco em iPhones. O projeto faz parte de uma atividade acadêmica dividida em etapas: a primeira focada em estruturação e estilização visual, e a segunda dedicada à implementação de interatividade e comportamentos dinâmicos.

- 🔗 **Acesse a prévia do projeto (GitHub Pages):** [Clique aqui para visualizar o site](https://matheus-soares-prog.github.io/Apple_eccomerce/menuapple.html)

---

## 🚀 Tecnologias Utilizadas
O projeto utiliza e integrará as seguintes tecnologias:
- **HTML5:** Estruturação semântica das páginas, organização de seções e integração de elementos multimídia.
- **CSS3:** Estilização visual minimalista inspirada no design da Apple, organização de layout e responsividade.
- **JavaScript:** (Em implementação para a Parte 2) Manipulação do DOM, interatividade da vitrine e dinâmicas da página.
- **Git & GitHub:** Controle de versão do código e publicação contínua via GitHub Pages.

---

## 🎨 Principais Funcionalidades
- **Vitrine de Produtos:** Apresentação estruturada dos modelos de iPhone com destaque visual.
- **Navegação Intuitiva:** Organização de seções para facilitar a visualização de detalhes e especificações.
- **Design Minimalista & Responsivo:** Layout adaptado para navegação em desktop e dispositivos móveis.
- **Integração Multimídia:** Uso de elementos visuais e vídeos integrados para enriquecer a experiência.

---

## 💡 O que eu aprendi / Desenvolvi
Neste projeto, aprofundei meus conhecimentos na criação de layouts do zero utilizando HTML e CSS puros, organizando folhas de estilo externas, posicionamento de elementos e boas práticas de marcação semântica. A próxima etapa focará na lógica de programação frontend com JavaScript.
