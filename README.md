# iMath — Protótipo de E-commerce Web

Protótipo de loja virtual desenvolvido para a disciplina de **Programação para a Internet 1 (PI1)**, com foco na construção de interfaces modernas, organização semântica e interatividade utilizando JavaScript puro (Vanilla JS).

---

### ✨ Funcionalidades e Páginas

- **Página Inicial (`menuapple.html`):** Apresentação institucional, vitrine principal e mídia integrada.
- **Catálogo de Produtos (`catalogo.html`):** Exibição dos modelos disponíveis com interações dinâmicas via JavaScript.
- **Comparativo de Modelos (`comparativo.html`):** Visualização lado a lado de especificações para apoio à escolha do produto.
- **Contato e Atendimento (`contato.html`):** Formulário interativo com validações e respostas dinâmicas ao usuário.

---

### 🛠️ Tecnologias e Conceitos Aplicados

- **HTML5:** Estruturação semântica das páginas e integração de mídia nativa (`<video>`).
- **CSS3:** Estilização responsiva e identidade visual limpa utilizando as fontes **Poppins** (títulos) e **Inter** (textos).
- **JavaScript (ES6+):** Manipulação do DOM e implementação de eventos interativos em scripts dedicados por página (`menuapple.js`, `catalogo.js`, `comparativo.js`, `contato.js`).
